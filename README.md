# Deutsch Lab

اختبار كمبيوتر بالألماني والعربي، جاهز لـ GitHub Pages.

- 250 سؤال اختيار من متعدد: 125 في كل اتجاه.
- السؤال الصحيح يُزال من الأسئلة المتبقية، والخطأ يعود للمراجعة.
- 578 تسجيلًا ألمانيًا كاملًا؛ لا توجد تسجيلات عربية.
- حفظ محلي للتقدم باستخدام localStorage، واختيار اتجاه التدريب وسرعة الصوت.

## رفعه على GitHub

1. فك ضغط الحزمة.
2. ارفع كل الملفات والمجلدات إلى جذر المستودع، مع الحفاظ على مجلد audio.
3. من Settings → Pages، اختر Deploy from a branch، ثم الفرع الذي رفعت عليه الملفات والمجلد /(root)، ثم Save.
4. افتح رابط الموقع بعد اكتمال النشر.

شرح GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

لا يحتاج المشروع إلى npm أو خادم أو مفاتيح API. افتح index.html محليًا، أو شغله على أي استضافة ملفات ثابتة.

## الملفات

- index.html: صفحة البداية.
- styles.css: تنسيق الواجهة.
- app.js: الواجهة والتدريب والحفظ وتشغيل الصوت.
- data.js: الأسئلة وربط كل نص ألماني بالتسجيل الخاص به.
- audio/: ملفات MP3 الألمانية.

احفظ البنية كما هي. ملفات الصوت تستخدم مسارات نسبية، لذلك يعمل المشروع أيضًا داخل مستودع فرعي على GitHub Pages.

## حفظ التقدم

كل زائر جديد يبدأ بصفر أسئلة محلولة. التقدم يُحفظ لكل متصفح على نفس أصل الموقع، ولا يُرفع إلى GitHub أو إلى خادم.
التقدم الموجود في نسخة HTML المحلية لا ينتقل تلقائيًا إلى عنوان GitHub Pages لأن عنوان الموقع مختلف.

## تعديل الأسئلة

الأسئلة في bank داخل data.js. الإجابة الصحيحة هي options[0] وتُخلط الاختيارات عند العرض.
كل سؤال له id ثابت. لا تغير المعرّفات إذا أردت الاحتفاظ بصلاحية تقدم المستخدمين السابق.
عند تغيير نص ألماني، أضف تسجيلًا مطابقًا إلى audio وحدث audio.clips؛ تشغيل الصوت لا يستخدم نطق المتصفح.
